Trade-J — Architecture, Components & Flows

Java 21 · Gradle · Spring Boot 3.4 · LMAX Disruptor · Chronicle Queue · DuckDB · NSE/BSE

What is Trade-J? A full-stack, event-sourced algorithmic trading platform for Indian equity markets (NSE/BSE). It ingests live market data via WebSocket, scans for trading opportunities using configurable criteria, evaluates strategies (including ML-backed strategies), manages orders through a deterministic OMS with position-level tracking, and supports LIVE / REPLAY / BACKTEST modes. Integrates with Dhan and Upstox brokers, and provides a Spring Boot HTTP API, a WebSocket gateway, and an interactive operator CLI. Full markdown reference: docs/ARCHITECTURE_REPORT.md (§0 diagram index).

2 Platform Capabilities

Market Data Ingestion

  • Live tick-level WebSocket feeds via Dhan (TICKER/QUOTE/FULL/DEPTH_20/DEPTH_200)
  • Upstox REST market data (analytics-only mode)
  • Depth update events, MarketTickEvent processing
  • Rate-limited via TokenBucket
  • Historical download and replay

Order Management (OMS)

  • Deterministic state machine: NEW → ACKNOWLEDGED → PARTIAL/FULL → CANCELLED/REJECTED
  • Event-sourced order lifecycle tracking
  • Bracket orders (Dhan), GTT orders
  • Slice orders for large fills
  • Order identity registry with rehydration
  • Fill reconciliation with alerts

Risk Management

  • PositionRiskHandler with configurable limits (max position, max loss, max notional)
  • Daily risk reset scheduler
  • TradingCircuitBreaker (max drawdown, consecutive losses, velocity checks)
  • Session-level risk (per-broker checks)
  • Position mismatch detection and alerts

Strategy & Scanning

  • StrategyPlugin architecture (StrategyPlugin, GraphStrategyPlugin)
  • Example strategies: DepthImbalanceStrategy, TickPriceChangeStrategy
  • ML-backed strategies via ThresholdMLInferenceEngine + ModelRegistry
  • Scanners: VolumeSpike, PCR range, %Change, Max OI Strike, streaming criteria
  • Institutional scanner: sector ranking, feature pipelines, candidate selection
  • Sandboxed strategy evaluation (StrategySandbox, GraphStrategySandbox)

Simulation & Backtesting

  • MatchingEngine with order book simulation
  • PnLLedger for trade-level P&L tracking
  • SimulatedOrderService (replace broker in non-LIVE modes)
  • ReplayRunner for historical tick replay
  • Google's DESIGN.md visual pipeline for strategy prototyping

Runtime Modes

  • LIVE — Real broker orders via WebSocket
  • REPLAY — Simulated orders from historical data
  • BACKTEST — Full backtest engine
  • Dual runtime architecture: Disruptor (low latency) + Graph DAG pipeline
  • BrokerRuntimeMode: DHAN_LIVE_WS, DHAN_SANDBOX, UPSTOX_TRADING_WS, UPSTOX_ANALYTICS_REST
