- **Layered Facade Pattern**: The module uses a three-tier internal structure. `SubscriptionCoordinator` holds the core logic for diffing desired vs. actual state and batching requests. `SubscriptionManager` acts as a facade that merges coordinator state with live wire state from `WebSocketMultiplexer`. `SubscriptionRecoveryManager` provides a dedicated entry point for reconnection events.
- **State Reconciliation**: `SubscriptionCoordinator.replaceSubscriptions` computes set differences (toAdd/toRemove) to minimize wire traffic, ensuring only necessary subscribe/unsubscribe calls are made to the `WebSocketMultiplexer` port.
- **Batching Strategy**: Internal methods `subscribeBatched` and `unsubscribeBatched` in `SubscriptionCoordinator` split large request lists into chunks defined by `batchSize`, preventing payload limits on the underlying WebSocket transport.
- **Recovery Mechanism**: `SubscriptionRecoveryManager` delegates to `SubscriptionManager.reconcileAfterReconnect`, which triggers a full resubscription of the `desiredByFeedMode` state held in the coordinator, ensuring state consistency after network interruptions.
