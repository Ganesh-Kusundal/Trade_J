- **Calculator layer** (`calculator/`): Pure static utility classes (`BlackScholesCalculator`, `IVSolver`, `MaxPainCalculator`) implementing numerical methods — Newton-Raphson IV solving, error-function-based CDF/PDF, open-interest pain aggregation — with no external dependencies.
- **Greeks caching layer** (`greeks/`): `OptionsAnalyticsCache` uses Caffeine LRU caches (50K greeks entries, 5K aggregate entries, 30s TTL) keyed by composite records (`GreeksKey`, `AggregateKey`); `OptionChainRegistry` provides a separate short-lived chain snapshot cache.
- **Pipeline integration** (`node/`): `GreeksCalcNode` extends `BasePipelineNode` from `:pipeline-core`, subscribes to `OptionChainUpdated` domain events, iterates strikes, solves IV via `IVSolver`, computes Greeks via `BlackScholesCalculator`, writes to cache, and publishes `GreeksComputed` events downstream.
- **Surface builder** (`surface/`): `VolatilitySurfaceBuilder` constructs per-expiry IV maps from chain snapshots using `IVSolver`, stores them in the cache, and returns a `VolatilitySurface` domain object.
- **Strike resolution service** (`service/`): `OptionStrikeResolver` delegates to `OptionsProvider` (from `:broker-api`) to select ATM/OTM strikes and resolve call/put instrument keys.
- **Dependency direction**: calculators are leaf utilities; greeks/cache depends on calculators; node and surface depend on both calculators and cache; service depends on broker-api port. All modules share `:core` domain types (`OptionGreeks`, `OptionChainSnapshot`, `DomainEvent`).
- **Build status**: excluded from production (`settings.gradle` omission per README.md); requires `OptionChainUpdated` event wiring before activation.
