- Entry point: `GatewayAutoConfiguration` (registered via `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`) conditionally creates core beans when `tradej.gateway.enabled=true`, wiring `GatewayTopicRouter`, `GatewayEventBridge`, `GatewayWebSocketHandler`, and `GatewayHealthIndicator`.
- Layering: transport layer (`WebSocketTransport` interface + `SpringWebSocketTransport` adapter) decouples routing logic from Spring's `WebSocketSession`; protocol layer (`GatewayTopic` enum, `GatewayBinaryCodec`) defines a 9-byte header wire format (1-byte topic ID + 8-byte sequence + payload); router layer (`GatewayTopicRouter`) maintains bidirectional topic-to-transport mappings with per-client bounded write queues and a shared publisher thread for non-blocking dispatch; bridge layer (`GatewayEventBridge`) maps 16+ domain event types to gateway topics via a `SerializerEntry` map and registers typed subscriptions on the `EventBus`.
- Dependency direction: `GatewayWebSocketHandler` → `GatewayTopicRouter` → `WebSocketTransport`; `GatewayEventBridge` → `GatewayTopicRouter` + `ObjectMapper` + optional `InstrumentResolver`; all layers depend only on the `protocol` and `transport` abstractions, not on Spring WebSocket internals directly.
- Observability: `GatewayHealthIndicator` exposes router metrics (sent/dropped/queue depth) via Spring Boot Actuator; `GatewayMetrics` registers Micrometer gauges for the same counters.
