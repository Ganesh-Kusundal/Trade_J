- **Disruptor Runtime (`runtime/disruptor`)**: Implements the core event backbone using `com.lmax:disruptor`. The `DisruptorEventBus` orchestrates a multi-stage pipeline (Graph Runtime → Strategy Sandbox → Async Dispatch) configured via `DisruptorPipelineBuilder`. It employs a `ShardedDisruptorEventBus` for symbol-based partitioning to maximize parallelism.
- **Hot-Path Ingestion (`runtime/hotpath`)**: Contains framework-free, pure Java orchestrators (`MarketDataPipeline`, `OrderPipeline`) that act as the entry points for external broker feeds. These pipelines handle rate limiting (via `TokenBucket`) and metrics before forwarding events to the Disruptor ring buffer.
- **Async Dispatch & Backpressure**: The `AsyncDispatchHandler` decouples blocking I/O (e.g., persistence) from the hot path by offloading subscriber dispatch to a dedicated background thread with a bounded queue, ensuring the Disruptor consumer threads remain non-blocking.
- **Dependency Direction**: `hotpath` depends on `disruptor` for event publication, while `disruptor` depends on domain ports and strategy/execution modules for pipeline stage implementation.
