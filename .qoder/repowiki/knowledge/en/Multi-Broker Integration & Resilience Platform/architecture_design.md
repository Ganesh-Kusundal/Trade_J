- **Plugin Architecture**: Broker implementations (Dhan, ICICI, Upstox) are discovered via Java `ServiceLoader` using the `BrokerProvider` SPI in `broker-api`, ensuring loose coupling between core logic and vendor-specific adapters.
- **Resilience Layer**: `broker-core` provides cross-cutting resilience patterns including `CircuitBreaker`, `RetryExecutor`, and `LoadBalancedBrokerGateway`, which aggregate multiple connections for failover and round-robin load balancing.
- **Unified Access Gateway**: `broker-gateway` exposes a fluent `BrokerHandle` API that wraps raw connections with standardized `GatewayResult` metadata (latency, source), while `BrokerRouter` enables auto-routing of historical data requests based on vendor-specific interval capabilities.
- **Simulation & Testing**: The platform supports paper trading and backtesting via `SimulationBrokerProvider` in the gateway module, allowing seamless switching between live and simulated environments without code changes.
