- **Dual Pipeline Orchestration**: The `:app` module wires two concurrent execution paths: a low-latency LMAX Disruptor ring buffer (`:runtime-disruptor`) for hot-path market data, and a composable DAG runtime (`:core` graph types) for flexible strategy composition.
- **Runtime Mode Switching**: A global `RuntimeMode` (LIVE/REPLAY/BACKTEST) injected via `RuntimeModeHolder` dictates data sourcing and order routing across all children, enabling identical strategy code to run against live brokers or simulated engines without modification.
- **Hexagonal Broker Boundary**: Children interact with external markets exclusively through the `IBrokerConnection` port defined in `:broker-api`, with `:app` selecting between Dhan or Upstox adapters at startup via Spring profiles.
- **Event-Sourced Consistency**: Cross-module state consistency (OMS, Portfolio, Risk) is enforced by a shared `DomainEvent` taxonomy from `:core`, persisted via Chronicle Queue and DuckDB in `:data-persistence`.
