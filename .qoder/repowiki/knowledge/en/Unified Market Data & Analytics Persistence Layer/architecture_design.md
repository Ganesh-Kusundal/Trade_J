- **Shared Embedded Storage**: All child modules (`analytics`, `feature-store`, `historical-ingest`, `persistence`) rely on embedded DuckDB instances, sharing a common JDBC driver dependency and similar connection management patterns (auto-reconnect, bootstrap-on-init).
- **Data Flow Contract**: `historical-ingest` populates the Hive-partitioned Parquet warehouse; `analytics` provides read-only access to this warehouse for backtesting; `feature-store` and `persistence` maintain separate runtime DuckDB databases for live tick/candle ingestion and order state tracking.
- **Modular Isolation**: Each module maintains its own `build.gradle` and database schema, preventing tight coupling while adhering to a unified data model (e.g., `paisa` pricing, `symbol/interval` keys) defined in the `:core` dependency.
