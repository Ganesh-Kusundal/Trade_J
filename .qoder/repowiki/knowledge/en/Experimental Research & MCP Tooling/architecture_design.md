- **Research Subsystem**: Organized into `api` (REST controllers), `core` (domain records like `ResearchSession` and `RunResult`), and `lab` (execution services). The `lab` package contains `StrategyLabService` and `ScannerLabService`, which drive backtests using `DuckDbAnalyticsEngine` and persist results to `DuckDbResearchStore`.
- **MCP Subsystem**: Located in `mcp-server`, it uses Spring AI's auto-configuration to expose `@McpTool` annotated classes (e.g., `EquityAnalyticsTools`) via an SSE transport. `McpServerController` provides health checks and catalog snapshots.
- **Data Persistence**: Both subsystems rely on DuckDB; `research` uses `DuckDbResearchStore` for experimental results (trades, hits), while `mcp` and `research` share `DuckDbAnalyticsEngine` for read-only market data access.
