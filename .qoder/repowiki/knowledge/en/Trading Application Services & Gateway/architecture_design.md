- **App Runtime (`app/`)**: A Spring Boot application (`TradingApplication`) acting as the central orchestrator. It exposes REST APIs (e.g., `AnalyticsController`, `AdminController`) and manages internal state via DuckDB and Chronicle Queue storage. Configuration is driven by `TradingProperties` with profile-specific YAMLs.
- **Gateway (`gateway/`)**: A specialized WebSocket server module decoupled from the main app logic. It uses a `GatewayTopicRouter` with per-client non-blocking write queues to broadcast domain events (ticks, orders, PnL) bridged via `GatewayEventBridge`. It supports binary protocol encoding for low-latency transmission.
- **CLI (`cli/`)**: A Picocli-based command-line interface (`TradeCli`) providing both interactive REPL and scriptable commands. It operates in two modes: 'attach' mode (HTTP calls to the running app) and 'standalone' mode (direct broker API interaction or local DuckDB queries).
