## Phase 10: Test Coverage Analysis

### 10.1 Test File Inventory
Count test files per broker module:
- Dhan: tests in adapter/, auth/, config/, constants/, depth/, historical/, http/, instrument/, mapper/, options/, orders/, validator/, websocket/
- ICICI: tests in auth/, historical/, http/, instrument/, mapper/, streaming/, websocket/
- Upstox: tests in adapter/, auth/, expired/, historical/, http/, instrument/, mapper/, websocket/

### 10.2 Test Classification
Categorize each test file:
- **Unit** — No external dependencies
- **Contract** — SPI contract tests
- **Integration** — Real broker endpoints
- **Smoke** — Quick sanity checks
- **Performance** — JMH benchmarks

### 10.3 Coverage Gap Analysis
Identify missing tests:
- Expired token / re-auth flows
- Invalid credentials
- Rate limit handling (429 responses)
- Empty responses (null/empty arrays)
- Malformed responses (wrong JSON structure)
- Partial option chains (missing strikes)
- Large historical downloads (pagination)
- Network failures (timeout, DNS, connection refused)
- Broker downtime / maintenance mode
- Duplicate WebSocket events
- WebSocket disconnect/reconnect cycling
- Mapping failures (unexpected fields, missing fields)

### 10.4 Contract Test Coverage
Verify each broker implements contract tests:
- `IBrokerConnectionContractTest`
- `WebSocketSupervisorContractTest`
- `InstrumentResolverContractTest`
- `TokenLifecycleServiceContractTest`

## Phase 12: Scoring & Report Generation

### 12.1 Scoring Methodology
- **Endpoint Coverage %**: (Implemented endpoints / Total SPI endpoints) × 100
- **Mapping Coverage %**: (Verified field mappings / Total fields) × 100
- **Test Coverage %**: (Tested endpoints / Total endpoints) × 100
- **Production Readiness %**: (Verified readiness items / Total items) × 100
- **Broker Readiness %**: Weighted average of above

### 12.2 Report Sections
1. Executive Summary
2. Broker Capability Matrix (with PASS/FAIL/PARTIAL/NOT_IMPLEMENTED)
3. Real Endpoint Validation Results (per endpoint, per broker)
4. Mapping Validation Results (field-by-field)
5. Historical Data Results (candle integrity)
6. Option Chain Results (strike/expiry/field verification)
7. WebSocket Results (connection, parsing, architecture)
8. Coverage Report (test inventory, classification, gaps)
9. Missing Tests (detailed list)
10. Production Readiness Findings (resilience, observability, secrets)
11. Risk Register (ranked risks with severity)
12. PASS/FAIL/PARTIAL per Broker
13. Final Certification Recommendation
